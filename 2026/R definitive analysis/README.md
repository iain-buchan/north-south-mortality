# R definitive analysis

This R code and data reproduces all results in the paper and its appendix.

- `ns_divide_analysis.R` — the analysis script
- `tot_death.xlsx` — deaths data provided by the Office for National Statistics (David Mais)
- `ns_output/` — tables (CSV) and figures (PDF, PNG, SVG, EMF) produced by the script

Unpacked from [complete_analysis_R.zip](../complete_analysis_R.zip).
