# 2026

Data and statistical code behind the paper:

**The north–south divide in English mortality, 1981–2024: a longitudinal population study**

## Files

- [complete_analysis_R.zip](complete_analysis_R.zip) — This R code and data reproduces all results in the paper and its appendix
- [data_cleaning.R](data_cleaning.R) — Copy of the ONS data cleaning script written by [Xingna Zhang](https://github.com/Nininn), a co-author on the paper, from [civicdatacoop/NorthSouthMortality](https://github.com/civicdatacoop/NorthSouthMortality/blob/main/data_cleaning.R)
- [tot_death.xlsx](tot_death.xlsx) — Copy of the deaths data provided by the Office for National Statistics (David Mais), from [civicdatacoop/NorthSouthMortality](https://github.com/civicdatacoop/NorthSouthMortality/blob/main/tot_death.xlsx)
