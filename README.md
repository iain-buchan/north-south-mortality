# North–South mortality

Data and statistical code behind studies of England's North–South divide in mortality rates.

## Papers

### 2026

The [2026](2026/) folder contains the data and code behind:

Kontopantelis E, Zhang X, Green M, Munford L, Barr B, Buchan I. **The north–south divide in English mortality, 1981–2024: a longitudinal population study.** *Lancet Public Health* 2026; 11: e847–56. https://doi.org/10.1016/S2468-2667(26)00195-7

Open Access under the CC BY 4.0 licence.

## Work in progress

### 2026 Causes

The [2026 Causes](2026%20Causes/) folder contains data and R code for a follow-up on the causes of death behind the divide, 1981–2025. It is exploratory and has not been peer reviewed.
